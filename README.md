# 📚 BookVault — Digital Library

A responsive and interactive **digital library web application** built with HTML, CSS, and JavaScript.

BookVault allows users to manage a personal collection of books directly in the browser, with features for adding, displaying, updating, and removing books.

This project was built as part of my JavaScript learning journey to practice object-oriented programming, DOM manipulation, event handling, form handling, and browser-based data management.

👉 [Visit BookVault](https://snehavyas-dev.github.io/BookVault/)

## 🎯 How It Works

BookVault uses JavaScript to manage a collection of book objects and dynamically display them in the library interface.

### 📖 Add a Book

Users can enter information about a book and add it to their personal library.

### 🔄 Manage Reading Status

Each book can have its reading status updated, allowing users to keep track of their reading progress.

### 🗑️ Remove a Book

Users can remove books from the library when they no longer want them in their collection.

### 🆔 Unique Book IDs

Each book is assigned a unique identifier to help manage individual books within the application.
